# Whole-requirement enforcement PoC

This branch integrates immutable requirements with the isolated Actor lifecycle.
The matching kagent Substrate variant owns the prepared compute gate and
guest-visible activation. It is not interchangeable with the Sessions variant.
This is an experimental reference, not an upstream-ready proposal or release.

The [complete PoC guide](https://github.com/vfalico/agentsuite-guardd/tree/poc/whole-requirement-v1/docs/poc)
contains source pins, companion setup, build/test instructions, demonstrated
results and limitations. Canonical module/import paths are unchanged.
